# Abid Adiyatma | Portfolio

Portfolio personal Abid Adiyatma, Business Intelligence Analyst yang berfokus pada analisis data, web scraping, otomasi proses, quality control, dan pengembangan web.

## Isi Portfolio

- Profil dan pengalaman kerja
- Studi kasus proyek
- Tech stack
- Sertifikasi dan pencapaian
- Kontak dan tautan profesional

## Teknologi

- HTML
- Tailwind CSS 4 (dibangun secara lokal)
- JavaScript
- Python dan Pandas
- SQL
- Microsoft Excel

## Menjalankan Lokal

1. Clone repository ini.
2. Install dependensi pengembangan dengan `npm install`.
3. Bangun CSS Tailwind dengan `npm run build:css`.
4. Buka `index.html` langsung di browser atau gunakan Live Server di VS Code.

Setiap kali kelas Tailwind diubah atau ditambahkan, jalankan kembali `npm run build:css`. Hasil build disimpan di `assets/css/tailwind.css` dan digunakan oleh situs statis.
