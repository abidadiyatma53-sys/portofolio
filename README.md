# Abid Adiyatma | Portfolio

Portfolio personal Abid Adiyatma, Business Intelligence Analyst yang berfokus pada analisis data, web scraping, otomasi proses, quality control, dan pengembangan web.

## Isi Portfolio

- Profil dan pengalaman kerja
- Studi kasus proyek
- Tech stack
- Sertifikasi dan pencapaian
- Kontak dan tautan profesional

## Teknologi

- HTML
- Tailwind CSS CDN
- JavaScript
- Python dan Pandas
- SQL
- Microsoft Excel

## Menjalankan Lokal

1. Clone repository ini.
2. Buka folder project.
3. Jalankan `index.html` langsung di browser atau gunakan Live Server di VS Code.

Project ini adalah static website, sehingga tidak membutuhkan proses build khusus.
